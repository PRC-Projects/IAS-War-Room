
# 🛡️ IAS War Room: Strategic Command Center (2027)

**IAS War Room** is not just a to-do list; it is a **situational awareness dashboard** designed for serious UPSC aspirants targeting the 2027 cycle. Built with a "Defensive Pessimism" philosophy, it combines tactical task management, AI-driven coaching, and deep analytics to ensure zero margin for error.

---

## 🚀 Mission Objective

To replace scattered notes and generic productivity apps with a centralized **Command Center** that tracks:

1. **Tactical Execution:** Daily tasks, deep work hours, and backlog management.
2. **Strategic Depth:** Syllabus coverage, long-term roadmaps, and preparation phases (Foundation/Prelims/Mains).
3. **Mental Endurance:** Burnout tracking and AI-driven motivation.

---

## ⚡ Key Features

### 1. 🏰 The War Room (Dashboard)

* **Doomsday Clock:** Live countdown to the estimated 2027 Prelims date.
* **AI SitRep:** Daily "Situation Report" generated by Gemini 2.5, analyzing your recent study patterns.
* **Active Intel Feed:** Auto-generated YouTube and Google News recommendations based on topics you studied yesterday.

### 2. 🧠 AI Tactical Coach

* **Context-Aware:** The AI reads your database (backlogs, efficiency, recent tasks) before answering.
* **Persona:** Acts as a strict but empathetic "General." It knows you are an Unreserved candidate and pushes for top 1% performance.
* **Capabilities:** Strategies for backlog clearing, answer writing tips, and reality checks.

### 3. 📊 Analytics Cockpit

* **Consistency Heatmap:** GitHub-style visualization of study streaks.
* **Subject Radar:** Spider chart showing mastery distribution (e.g., History vs. Polity).
* **Cognitive Load Analysis:** Tracks Active Output (Writing/Mocks) vs. Passive Input (Reading/Videos).

### 4. ⚔️ The Armory (Library & Syllabus)

* **Resource Inventory:** Track books (Laxmikanth, Spectrum) and chapter progress.
* **Interactive War Map:** A clickable tree of the entire UPSC Syllabus (GS1-4). Mark topics as **Weak (Red)**, **Average (Yellow)**, or **Strong (Green)**.

### 5. 🚩 Strategic Roadmap

* **Timeline Visualization:** Plan Foundation, Prelims, and Mains phases.
* **Milestone Tracking:** Break down macro goals (Yearly) into micro steps (Milestones).
* **Priority Matrix:** Tag objectives as High/Medium/Low priority.

### 6. ⚓ Captain's Log (Journal)

* **Mood Tracking:** Log daily morale to detect burnout patterns.
* **Pattern Recognition:** Correlate sleep/diet tags with study performance.

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite), Tailwind CSS
* **Backend / DB:** Supabase (PostgreSQL, Auth, RLS)
* **AI Engine:** Google Gemini API (`gemini-2.5-flash`)
* **Visualization:** Recharts
* **Icons:** Lucide React
* **Date Management:** Date-fns

## ⚙️ Installation & Setup

### Prerequisites

* Node.js (v18+)
* A generic Supabase project
* Google Gemini API Key

### 1. Clone the Repository

```bash
git clone https://github.com/https://github.com/PRC-Projects/IAS-War-Room.git
cd ias-war-room

```

### 2. Install Dependencies

```bash
npm install
# Fix for legacy peer dependencies if needed:
npm install --legacy-peer-deps

```

### 3. Environment Variables

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_GEMINI_API_KEY=your_google_gemini_key

```

### 4. Database Setup (Supabase SQL)

Go to your Supabase **SQL Editor** and run the schema scripts.
*(Note: Ensure you enable Row Level Security (RLS) policies for security).*

**Tables required:**

* `tasks` (Daily study missions)
* `resources` (Books and progress)
* `syllabus_progress` (Topic mastery status)
* `journal_entries` (Mental health logs)
* `targets` (Strategic goals)
* `target_milestones` (Sub-tasks for goals)

### 5. Run the Application

```bash
npm run dev

```

Access the War Room at `http://localhost:5173`.
